# subtitlefixer

Free subtitle tools that run entirely in your browser: shift timings, fix encoding, convert SRT / VTT / ASS. Your files never leave your device.

- Stack: Astro + TypeScript + Tailwind, static, Cloudflare Pages
- Roadmap: [`docs/PLAN.md`](docs/PLAN.md)
- Rules for AI agents: [`AGENTS.md`](AGENTS.md)

```bash
npm install
npm run dev
npm run build
npm test
```
